## 2. What a CA / CS actually does

| Role | Typical help for incorporation |
|------|--------------------------------|
| **CA (Chartered Accountant)** | Package: DSC, SPICe+, PAN/TAN, GST later, books, annual filings. Most founders hire a CA firm that also coordinates CS work. |
| **CS (Company Secretary)** | MCA forms, MoA/AoA, ROC compliance, resolutions. Sometimes bundled in the CA package. |
| **You** | Confirm **Pvt Ltd** + company name, send Aadhaar/PAN/address proofs, video KYC for DSC, sign digitally, open bank account, run Meta verification + App Review. |

**DIY without CA?** Possible on [mca.gov.in](https://www.mca.gov.in) if you know SPICe+. For a first company, a CA package is usually cheaper than fixing rejected filings.

**How to hire (from home):**
1. Ask for a written package: incorporation + DSC + first-year basic compliance quote.
2. Confirm they file **SPICe+** (company + PAN + TAN in one flow).
3. Prefer someone who has done **startup / DPIIT** filings if you want Startup India later.
4. Pay after you see a clear checklist and timeline — not vague “trust me” WhatsApp only.

## 4. End-to-end process (checklist)

### Phase A — Prep (1–3 days, from home)

- [x] Entity: **Private Limited (Pvt Ltd)** — decided 2026-07-27
- [ ] Identify **2nd director / shareholder** (Pvt Ltd requirement — ask CA for minimal setup)
- [ ] Shortlist 2–3 **company names** (legal name can differ from brand “Halo Aid”)
- [ ] Fix **registered office** (home OK if you have address proof + owner NOC if not solely yours)
- [ ] Gather docs (see §5) for both directors
- [ ] Hire CA/CS; get written fee + timeline for **Pvt Ltd SPICe+**

### Phase B — Incorporation (mostly from home, ~7–21 days)

- [ ] **DSC** (Digital Signature Certificate) for each director — usually **video KYC**
- [ ] **DIN** (often allotted inside SPICe+)
- [ ] Name reservation / SPICe+ name part
- [ ] CA files **SPICe+** (incorporation + e-MoA / e-AoA + PAN + TAN)
- [ ] You e-sign as prompted
- [ ] Receive **Certificate of Incorporation (COI)** + company **PAN** + **TAN**
- [ ] Save PDFs of COI, PAN, MoA, AoA in a secure folder

### Phase C — Bank current account (3–14 days; often 1 visit)

- [ ] Pick bank (ask CA which ones do **video KYC** for startups in your city)
- [ ] Submit COI, PAN, MoA/AoA, address proof, director KYC
- [ ] Complete KYC (branch visit **if** bank requires)
- [ ] Get account number + cancelled cheque / bank letter (useful for Meta / GST)

### Phase D — Tax IDs when needed (from home)

- [ ] **GST** — required when you cross threshold / want B2B invoices; many startups register early for clinic invoices. CA files online.
- [ ] Optional later: **DPIIT Startup India** (free; helps some compliance exemptions — ask CA)

### Phase E — Meta Business verification (free, from home, ~3–14 days)

> **Not** the Business Suite home card “Become a verified business / Meta Verified badge.”

- [ ] Confirm email on the business portfolio
- [ ] [business.facebook.com](https://business.facebook.com) → **Settings** → **Business info** (legal name, address, phone, website matching docs)
- [ ] **Security Center** → **Start verification**
- [ ] Upload docs Meta asks for (COI / registration / tax / utility — follow their list)
- [ ] Confirm via **domain email**, phone, or **domain verification**
- [ ] Wait until status = **Verified**

### Phase F — Instagram App Review (free, from home, ~1–4+ weeks)

App: the one behind `INSTAGRAM_APP_ID` (Halo Aid-IG / Instagram Login path). Permissions only:

- `instagram_business_basic`
- `instagram_business_manage_messages`
- `instagram_business_manage_comments`

- [ ] Privacy / Terms / data-deletion URLs live
- [ ] Record screencast: Connect → DM reply → comment public reply + DM
- [ ] Request **Advanced Access** for those three only
- [ ] Paste use-case copy framed as **clinic Instagram receptionist / appointment FAQs** (not diagnosis)
- [ ] Submit; track status; resubmit if Meta asks for fixes

### Phase G — After Advanced Access

- [ ] Smoke-test Connect with a **non-tester** Instagram pro account
- [ ] Keep product hardening (see launch checklist)

## 5. Documents checklist (typical)

**Directors / promoters**
- PAN, Aadhaar
- Photo, email, mobile
- Address proof (as CA specifies)

**Registered office**
- Utility bill / tax receipt (recent, as MCA requires)
- NOC from owner if premises not in your sole name
- Rent agreement if rented (if CA asks)

**After incorporation (for bank / Meta)**
- COI PDF
- Company PAN
- MoA + AoA
- Board resolution / authority letter (bank often wants this — CA drafts)
- Cancelled cheque or bank letter (after account opens)

## 7. Money investment (indicative INR, 2025–26)

Confirm quotes — packages vary by city and authorized capital.

### 7.1 One-time setup (year 0)

| Item | Low | Typical | Notes |
|------|-----|---------|--------|
| DSC (per director) | ₹1,000 | ₹1,500–2,500 | Video KYC |
| MCA / stamp / SPICe+ govt fees | ₹2,000 | ₹5,000–12,000 | Depends on capital & state stamp |
| CA/CS professional (incorporation package) | ₹5,000 | ₹8,000–15,000 | Often bundled with DSC |
| **Incorporation all-in** | **₹8,000** | **₹12,000–25,000** | Common WhatsApp packages |
| Bank current account | ₹0 | ₹0–5k | Min balance varies |
| GST registration (CA) | ₹0 | ₹1,500–5,000 | Govt fee usually nil/low |
| Domain email (for Meta) | ₹0 | ₹500–2,000/yr | Strongly recommended vs Gmail-only |
| **Meta verification + App Review** | ₹0 | ₹0 | Free |

**Budget band to start:** **₹15,000–40,000** cash in year 0 for entity + bank + GST + basics.

### 7.2 Recurring (year 1+, Pvt Ltd)

| Item | Rough annual |
|------|----------------|
| Auditor + ROC annual filings (basic) | ₹15,000–40,000+ |
| CA bookkeeping / GST returns (if registered) | ₹12,000–36,000+ |
| DSC renewal (when expired) | ₹1,000–2,500 |

Ask CA for a **Pvt Ltd year-1 total cost** quote (incorporation + audit + ROC + GST if applicable) up front.

### 7.3 What you do *not* need to pay for App Review
- Meta App Review fee (none)
- “Meta Verified badge” subscription (unrelated)
- Extra Instagram permissions you don’t use
