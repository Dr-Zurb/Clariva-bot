# Weekday rhythm

Default character of each weekday. The week template inherits these labels. Do not re-decide "what kind of day is today" every morning.

Clinic/OPD hours still win — if Monday is a full OPD day, the queue-push list is three messages, not a deep-work fantasy.

| Day | Character | What belongs here |
|-----|-----------|-------------------|
| **Mon** | Queue push | Every external ask: CA, bank, attorney, Meta, vendors. Their clock starts today. |
| **Tue** | Deep build | Protected. Features, endpoints, the work that needs a quiet block. |
| **Wed** | Deep build | Same as Tuesday. |
| **Thu** | Build + paperwork | Build continues. Exactly **one** legal/compliance item, finished — not deferred. |
| **Fri** | Ship / chase / review | Close what's half-done. Nudge every Monday ask that got no reply. Week review. |
| **Sat** | Customers | Clinics are open. Demos, walk-ins, the three names on G1. |
| **Sun** | Slow build + next-week preplan | Work, just slower. Product leftover or clinic EHR. Night: `tracks.md` + next week's Sunday preplan. Break only when you feel like it — not a scheduled off day. |

Why this shape: external latency is the real bottleneck. Monday fires the queues so they cook while Tuesday–Wednesday produce. Friday is for closing loops, not opening new ones.

If a week needs a different shape (travel, a launch, a Meta review deadline), override the day's label in that week's file. Don't rewrite this file for a one-off.
