# Notebook — thoughts and chosen

**Date:** 20 Oct 2026. **Built:** 20 Oct 2026. **Program:** social assist. This is not a new phase number. Phases 9–11 stay the analytics work.

## Gate

A thought and a chosen card open the same notebook. Closing it keeps the title and the note. The note can hold a heading, a bullet, a numbered line, a to-do, a quote, a file, and a link. Enter, Backspace, and the arrow keys move through the lines as one page. The forward step is still **Choose** or **Start making**.

## Left as they are

Four columns, in the same order. No script column. No templates. No AI. Templates and the hook stay on Making, after the format is chosen.

## What changes

1. The open card saves as the doctor types. A blank title is saved as "untitled". Closing keeps the card. **Save** leaves the thought sheet. Delete sits in the card menu.
2. A note holds 4000 characters. Near the end, the sheet says how many are left. The phone capture uses the same limit.
3. Enter splits a line at the cursor. Enter on an empty bullet, number, to-do, or quote ends that block. Backspace at the start joins the line above. Up and Down move between lines. `/` filters the block menu. An empty note says to type `/`.
4. New blocks: bullet (`* `), numbered (`1. `), quote (`> `). A to-do stays `- [ ] `. An older `- ` line stays an unticked to-do. Pasting a link on an empty line makes a link block. A file dropped on a line is placed there.
5. The empty resources rail is a paperclip. The title and the note sit in a reading column. The sheet header is the column picker. Choosing Making asks for the format. Choosing Ready without a file does not move the card.
